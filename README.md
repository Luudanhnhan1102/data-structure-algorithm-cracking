# Data Structure and Algorithms


## Contribution's Guide
- Problems are organized by DSA topics and difficulty levels (Easy, Medium, Hard).
- Create a directory with name `<problem_id>. <Problem-Name>` inside the appropriate topic and difficulty folder.
- Use the template files to create your solution:
  - `des.md` - Use the description template (`des.template.md`)
  - `sol.md` - Use the solution template (`sol.template.md`)

For example:
```
Binary-Search/
└── Easy/
    └── 35. Search-Insert-Position/
        ├── des.md
        └── sol.md
```

- If you are new with markdown, follow these guidelines: <https://github.com/DavidAnson/markdownlint/blob/v0.35.0/doc/Rules.md>

## Template Files
### Description Template (`des.template.md`)
The description template should be used to document the problem statement and includes:
- Problem title and link
- Problem description
- Examples
- Constraints

### Solution Template (`sol.template.md`)
The solution template provides a structured approach to document your solution:
- Topics and goals
- Key challenges
- Multiple approaches (brute force and optimal)
- Time and space complexity analysis
- Detailed explanations
- Key takeaways and further improvements
